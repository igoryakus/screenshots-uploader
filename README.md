# shothost

**ShotHost** — это легкая утилита, которая автоматически загружает ваши скриншоты на личный VPS через SSH/SFTP и мгновенно копирует ссылку для просмотра в буфер обмена. Сохраняйте полный контроль над своими медиафайлами, не полагаясь на сторонние фотохостинги.

### Возможности
* **Мгновенная загрузка:** Отправляйте скриншоты на сервер в тот же момент, когда файлы записываются на диск.
* **Автокопирование URL:** Готовая к отправке ссылка генерируется сразу и вы можете ей пользоваться, пока в фоне файл копируется на сервер.
* **Приватность на своем сервере:** Ваши изображения остаются в безопасности на вашем собственном VPS под вашим полным контролем.
* **Максимальная скорость:** Мгновенная прямая загрузка на VPS без задержек публичных хостингов.
* **Отсутствие рекламы:** Полное отсутствие баннеров, всплывающих окон, вотермарок и капч.
* **Вечное хранение:** Ваши файлы размещены навсегда и никогда не удалятся автоматически.

### Приложение для macOS

В папке [`macos-app`](macos-app) лежит приложение для строки меню, которое заменяет `shothost.sh`, `fswatch` и LaunchAgent. Все параметры задаются в окне настроек, а не в тексте скрипта.

* **Сборка:** нужны Xcode или Command Line Tools (`xcode-select --install`), затем `./macos-app/build-app.sh`. Готовое приложение появится в `macos-app/build/ShotHost.app`, его нужно перенести в «Программы». Собранный архив также можно скачать из артефактов GitHub Actions (workflow «macOS app»).
* **Первый запуск:** приложение подписано без сертификата разработчика, поэтому в первый раз откройте его через правый клик и «Открыть».
* **Настройка:** при первом запуске откроется окно настроек. Укажите папку со скриншотами, сервер, порт, пользователя, папку на сервере, SSH-ключ и адрес ShotHost, затем нажмите «Проверить соединение» и «Сохранить».
* **Работа:** новые файлы в папке переименовываются и загружаются так же, как скриптом, ссылка сразу копируется в буфер обмена, а после загрузки приходит уведомление с кнопкой «Открыть». В меню есть пауза, ручная загрузка файла, последние ссылки и автозапуск при входе в систему.
* **Если раньше пользовались скриптом**, выгрузите LaunchAgent, чтобы файлы не загружались дважды: `launchctl unload ~/Library/LaunchAgents/com.user.shothost.plist`.
